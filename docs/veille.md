# Méthodologie de veille technologique

Cadence : deux créneaux de 30 minutes par semaine et revue mensuelle des choix du projet.

Sources suivies :
- OWASP Cheat Sheet Series : sécurité web et API ;
- CNIL : mots de passe, cookies, RGPD ;
- documentation FastAPI / SQLAlchemy ;
- documentation TypeScript ;
- Stripe Docs : paiements et webhooks ;
- web.dev / Google Search Central : performance, accessibilité et SEO ;
- MDN : compatibilité et standards web.

Méthode : chaque élément utile est enregistré dans un tableau avec date, source, sujet, impact potentiel, décision et statut. Une recommandation n'est appliquée que si elle répond à une contrainte réelle du projet.
